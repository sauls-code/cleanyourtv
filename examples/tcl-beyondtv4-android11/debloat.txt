# TCL BeyondTV4 (reports as "Smart TV Pro", device BeyondTV4, board rtd288o, client type
# TCL-AU-RTD51M-S1, software V8-R51MT05-LF1V620 AR09), Android 11 (SDK 30), build RP1A.200622.001
# release-keys. Australia retail unit (preloaded Stan, SBS On Demand).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-beyondtv4-android11/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-beyondtv4-android11/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (Google TV Launcher). Pass to restore.sh as 2nd arg.
# Live TV app: com.tcl.tv (owns HDMI/tuner playback, leanback action present). Keep com.tcl.tvinput too.
#
# Tested on a real unit: Wi-Fi stayed up, D-pad navigation, HDMI inputs dropdown via TvInputManager,
# and streaming apps (Apple TV, Netflix, Stan, Disney+) all worked after debloating and launcher installation.
#
# Quirks on this firmware:
# - Setup wizard (com.google.android.tungsten.setupwraith) claims HOME with priority 1 once launcherx
#   is disabled. On this firmware, Wi-Fi networks belong to android.uid.system:1000 (verified with
#   dumpsys wifi), so setupwraith can safely be disabled without dropping Wi-Fi.
# - screencap writes an empty file while Live TV/HDMI or secure surface is on screen. Press Home first.
#
